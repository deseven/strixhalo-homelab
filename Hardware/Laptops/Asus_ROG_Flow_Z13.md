# Asus ROG Flow Z13 (2025) GZ302EA

![Asus ROG Flow Z13](./asus-rog-flow-z13.jpg)

[[OFFICIAL PRODUCT PAGE](https://rog.asus.com/laptops/rog-flow/rog-flow-z13-2025/)]

The ROG Flow Z13 (2025) is the first gaming convertible tablet to feature AMD's flagship Strix Halo processor. This 13.4-inch 2-in-1 device brings exceptional CPU and GPU performance in a compact, portable form factor, positioning it as the fastest 13-inch device currently available.

Availability: February 25, 2025 (EU pricing starts at €2,499)

## Key Specifications

| Component | Details |
|-----------|---------|
| **Processor** | AMD Ryzen AI Max+ 395 (16-core Zen 5, up to 5.1 GHz) or Ryzen AI Max 390 (12-core) |
| **GPU** | AMD Radeon 8060S (RDNA 3.5, competitive with RTX 4070 Laptop) |
| **Memory** | Up to 128GB unified LPDDR5x-8000 (configurations: 32GB, 64GB, 128GB) |
| **Storage** | Up to 1TB PCIe 4.0 NVMe M.2 SSD (2230 form factor, user-replaceable) |
| **Display** | 13.4" QHD (2560×1600, 16:10) IPS, 180Hz, 500 nits, PWM-free |
| **Connectivity** | 2x USB-C 4.0 (40 Gbps), USB-A 3.2 Gen.2, HDMI 2.1, 3.5mm jack, microSD card reader |
| **Wireless** | Wi-Fi 7 (MediaTek MT7925), Bluetooth 5.4 |
| **Battery** | 70Wh (increased from 56Wh) |
| **Weight** | 1.23 kg (tablet only), 1.62 kg (with keyboard cover) |
| **Thickness** | 14mm (tablet), 20mm (with keyboard) |
| **Cooling** | Vapor chamber + liquid metal thermal interface |
| **Power Supply** | 200W USB-C PD adapter |

## Performance Highlights

- **CPU Performance**: Comparable to Ryzen 9 7945HX3D in multi-core scenarios (~50-70% faster than previous generation Core i9-13900H)
- **GPU Performance**: Radeon 8060S is the fastest x86 iGPU, matching or exceeding RTX 4070 Laptop at 65-75W TGP
- **Gaming**: Handles modern titles at 1080p ultra settings with playable frame rates; QHD gaming is feasible but demanding
- **Creative Workflows**: With up to 96GB unified VRAM (128GB model), excellent for AI and content creation tasks
- **Battery Life**: Up to 9:20 hours at 150 nits brightness (WiFi), or 12:44 hours video playback

## Design & Features

- **Build Quality**: Premium aluminum chassis with anti-fingerprint coating
- **Convertible Form Factor**: 170° hinge allows multiple usage modes (laptop, tent, tablet)
- **Included Keyboard Cover**: Magnetically attached with leather-like backing, acts as screen protector
- **Touchscreen**: Capacitive 13.4" with native pen support and Gorilla Glass DCX
- **Cameras**: 5MP front with IR face recognition + 13MP rear
- **Kickstand**: Integrated kickstand supporting up to 170° opening angle

## Connectivity & I/O

- **USB 4.0**: Two Thunderbolt 4 compatible ports with DisplayPort 2.1 and Power Delivery 3.0
- **Display Output**: Supports external displays via USB-C with high-speed data transfer
- **XG Mobile Support**: Compatible with Asus ROG XG Mobile external GPU dock
- **Network**: Dual 10G Ethernet not included (unlike some mini PCs), standard networking via Wi-Fi 7

## Notable Improvements vs. Previous Generation

- Refresh rate upgraded from 165Hz to 180Hz
- Significantly improved CPU performance (16 Zen 5 cores vs. older Intel gen)
- Integrated GPU now rivals dedicated RTX 4070 Laptop GPUs
- Battery capacity increased from 56Wh to 70Wh
- Improved cooling with vapor chamber and liquid metal
- Support for up to 128GB unified memory (higher VRAM allocation for GPU)

## Limitations

- **RAM Not Upgradeable**: Soldered memory limits future upgrades
- **Storage**: Only M.2-2230 form factor SSD with limited maintenance access
- **Speakers**: Stereo speakers are relatively weak; headphones recommended
- **Noise**: Fans become audible in Turbo mode (~45 dB(A) during gaming)
- **Maintenance**: Very limited serviceability; only SSD is user-accessible

## Power Consumption & Thermal Management

- **Idle**: 10.4-17.3W at 150 nits
- **Gaming**: ~110W sustained
- **Stress Test Peak**: 138W (quickly stabilizes at ~110-116W for combined CPU/GPU)
- **Temperatures**: Max 42.5°C (upper surface), stays cool for lap use
- **Vapor Chamber**: Efficiently dissipates heat through top exhaust vents

## Use Cases

- **Professional Gaming**: Excellent for gaming at 1080p or 1440p with maximum settings
- **Content Creation**: 32GB+ configurations suitable for video editing, 3D rendering with GPU acceleration
- **AI/ML Development**: High unified memory (up to 128GB) ideal for local LLM inference and AI experimentation
- **Portable Workstation**: Rivals 14-15" laptops in performance while maintaining portability
- **Data Science**: VRAM allocation flexibility supports large dataset analysis
