# Hilbert Super Workstation

![Hilbert Super Workstation](./hilbert_super_workstation.jpg)

[[OFFICIAL PRODUCT PAGE](https://hilbert.infplane.com/pages/hilbert)]
[[KICKSTARTER DESCRIPTION](https://www.kickstarter.com/projects/infplane/hilbert-agentic-computer/description)]

Infplane's Hilbert is a portable agentic supercomputer aimed at coding, agent workflows, local AI, CAD/EDA, and gaming. The launch messaging centers on an AMD Ryzen AI Max+ 395 platform, high-bandwidth local memory, and a compact 199 mm cube chassis.

Availability: crowdfunding / reserve-now launch.

### Highlights
- Designed for coding and creating agent workflows.
- Claims support for local 235B MoE or 8x32B LLMs.
- Promoted for OpenClaw, CAD/EDA, image generation, video generation, TTS, and AAA gaming.
- Mentions Windows, Cachy OS, SteamOS, and Fedora as supported operating systems.
- Highlights 96 GB "Ultimate VRAM" and 116 GB dynamic memory capacity.
- Claims 8000 MHz memory, with up to 8533 MHz configuration.
- Uses KLEENE, Infplane's motherboard-level control system, to coordinate CPU, GPU, and memory performance.
